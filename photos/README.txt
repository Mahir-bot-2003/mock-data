📸 DROP YOUR PHOTOS HERE
================================

Place your image files in this folder, then open index.html
and update the "photos:" section in the JavaScript config
(search for "YOUR PHOTOS" in the file).

NAME YOUR FILES:
  photo1.jpg  →  replaces polaroid #1
  photo2.jpg  →  replaces polaroid #2
  photo3.jpg  →  replaces polaroid #3
  photo4.jpg  →  replaces polaroid #4

SUPPORTED FORMATS:
  .jpg / .jpeg / .png / .webp / .gif / .avif

TIPS:
  • Any file size works — the site crops photos to fit
  • Portrait or landscape photos both look great
  • For best results use photos wider than 600px

TO ADD MORE PHOTOS:
  1. Add more image files here (photo5.jpg, photo6.jpg, etc.)
  2. In index.html, copy one { } block in the photos: array
  3. Update the id, title, date, sticker, image path & story

Happy editing! 💕
